## Formats

1. **Vertical demo (30-45s):** chip + OLED close-up, tokens appearing, tok/s counter. No talking head needed; text overlays EN, captions ES.
2. **X thread (6-10 tweets):** numbers, table screenshot, one GIF, link in last tweet.
3. **Long-form (monthly):** one deep-dive per month (recipe walkthrough).

- Top referrer of repo traffic (tells you where the audience actually is)
